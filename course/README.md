# course/ — everything needed to make a lesson page

- `transcripts/` — all 21 lesson transcripts with the lesson-page text (verbatim prompts, links). `INDEX.md` lists them in order; `DOWNLOADS.md` lists each lesson's code download.
- `lesson-04-candidates/` — three candidate designs for the lesson 04 page (v1 iterative, v2 redesign, v3 independent) and an instructional-design review of v1. v3 is the current draft in `../sops/sop-lesson-04.html`.
- `LESSON-PAGE-RULES.md` — what the learner wants from every lesson page. Read before writing one.
- `how-rays-agent-works.md` — plain-English system diagram of the finished agent.
- `what-ray-provides-per-lesson.md` — downloads, prompts, and repo tags per lesson (tags run two behind video numbers).
- `beyond-the-course.md` — what to add after lesson 17, ranked by effort.

The public repo: https://github.com/ray-amjad/slack-agent-course
